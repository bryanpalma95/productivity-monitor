Transcripción de Audio

Configura tu API key de Groq para habilitar transcripción precisa con Whisper. Groq es gratuito — solo crea una cuenta en console.groq.com y genera una API key.

Sin API key — usando reconocimiento de voz del navegador como fallback.
¿Cómo obtener una API key de Groq gratis?
  1. Ve a console.groq.com
  2. Crea una cuenta gratuita (puedes usar Google)
  3. En el menú lateral, haz clic en API Keys
  4. Clic en Create API Key
  5. Copia la key (empieza con gsk_) y pégala aquí

Resumen IA

Configura tu API key de OpenRouter para habilitar el resumen automático de sesiones con IA. OpenRouter es gratuito — sin tarjeta de crédito, y siempre usa el mejor modelo disponible.

Sin API key — el Resumen IA no estará disponible.
¿Cómo obtener una API key de OpenRouter gratis?
  1. Ve a openrouter.ai/keys
  2. Crea una cuenta gratuita (puedes usar Google)
  3. Clic en Create Key
  4. Copia la key (empieza con sk-or-) y pégala aquí
